Repository evidence

Modern stack

The repository uses Next.js 16, React 19, TypeScript, Supabase, Hanzi Writer, and Tesseract.js.

Learning modules

The codebase includes HSK content, games, stories, pronunciation, dictionary tools, flashcards, quests, mistake tracking, and progress analysis.

Offline-aware design

The product includes an Offline Library module and local storage utilities alongside cloud sync.

Testing

The package exposes lint and automated test scripts for the learning logic.

The problem

Language learning becomes difficult when vocabulary, review, stories, writing practice, pronunciation, progress, and motivation are spread across separate tools with no shared learning state.

The solution

The application brings those workflows together through a daily learning path, chapter progression, spaced repetition, mistake review, HSK course content, stories, games, personalized goals, and progress analytics.

Engineering decisions

Client-heavy learning stateThe main product coordinates profile goals, XP, streaks, reviews, mistakes, chapter progress, rewards, voice preferences, and study history.
Progressive loadingLarge modules such as mock exams, adaptive planning, offline library, and HSK deep-dives are dynamically loaded rather than forced into the initial interface.
Learning algorithmsThe repository includes spaced repetition, daily session building, mistake review, flashcard scheduling, skill evidence, placement logic, and study recommendations.
Cloud optionalitySupabase-backed synchronization is separated from local storage so the product can still support local workflows.

System flow

The project is easier to understand as a sequence of responsibilities:

Profile & goals→Learning engine→Review / mistakes→HSK content & games→Progress insights→Optional cloud sync

What I’d improve next

Break the very large page controller into smaller feature-level state containers.
Add broader end-to-end coverage for critical study flows.
Strengthen accessibility testing for game and handwriting interactions.
Add clearer product analytics for which learning interventions improve retention.

What I learned

This project taught me how quickly a learning product becomes a systems problem. Content is only one layer; scheduling, feedback, motivation, persistence, accessibility, and progress evidence all need to work together.
